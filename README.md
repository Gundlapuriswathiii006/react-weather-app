
React Weather Application

Overview

The React Weather Application is a frontend web app that allows users to check real-time weather information for different locations. The app fetches live weather data using the OpenWeather API and location details using GeoData APIs, providing accurate and up-to-date weather conditions.

This project focuses on API integration, React state management, and dynamic UI updates.

⸻

Features
	•	Search weather by city name
	•	Fetch real-time weather data
	•	Display temperature, humidity, wind speed, and weather conditions
	•	Location-based data handling using GeoData API
	•	Clean and responsive UI
	•	Error handling for invalid city names

⸻

How It Works
	1.	User enters a city name in the search input
	2.	The app fetches location coordinates using the GeoData API
	3.	Coordinates are passed to the OpenWeather API
	4.	Weather data is retrieved and displayed dynamically on the UI
	5.	UI updates automatically using React state and hooks

⸻

APIs Used
	•	OpenWeather API
Used to fetch real-time weather details such as temperature, weather condition, humidity, and wind speed
	•	GeoData API
Used to convert city names into geographic coordinates (latitude and longitude)

⸻

Tech Stack
	•	Frontend Framework: React.js
	•	API Integration: Fetch / Axios
	•	State Management: React Hooks (useState, useEffect)
	•	Styling: CSS
	•	Build Tool: Vite
